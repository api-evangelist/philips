# Philips (philips)

A Dutch multinational health technology company focused on diagnostic imaging, patient monitoring, image-guided therapy, ultrasound, sleep and respiratory care, and connected care solutions. Philips transitioned from a diversified electronics conglomerate to a dedicated healthcare technology leader and operates the HealthSuite Digital Platform (HSDP) as its cloud-based platform for connected health applications. HSDP exposes Identity & Access Management, Provisioning, IoT/Connect, Foundation, Cognitive, Clinical Data, and Notification building blocks for consumer health and professional healthcare applications; access is gated behind a customer portal at www.hsdp.io with API documentation distributed to authenticated customers and partners rather than the open public web. The legacy Philips Hue lighting API is no longer a Philips offering - Hue has been spun off into Signify.
